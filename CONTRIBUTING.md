# Contributing to F1 Racecraft Index

Thank you for your interest in contributing to F1 Racecraft Index.

This project is a Formula 1 analytics portfolio project built with Python, OpenF1 API data, SQLite, pandas, and matplotlib. Contributions are welcome if they improve the reliability, clarity, documentation, or analytical value of the project.

## Good contribution areas

Helpful contributions include:

- Fixing bugs
- Improving documentation
- Testing the pipeline with additional race weekends
- Validating OpenF1 endpoint behavior
- Improving chart readability
- Suggesting clearer feature-engineering logic
- Adding small, explainable analytics improvements

## Before opening an issue

Before opening an issue, please check:

1. Whether the issue already exists.
2. Whether the behavior is related to missing or incomplete OpenF1 data.
3. Whether the README, runbook, methodology, or data dictionary already explains the limitation.

## Before opening a pull request

Before opening a pull request:

1. Fork the repository.
2. Create a new branch with a clear name.
3. Keep the change focused.
4. Update documentation if the behavior, outputs, or methodology changes.
5. Make sure the project still runs successfully.
