# Security Policy

## Supported versions

This is a portfolio and educational analytics project. The current public version of the repository is the only supported version.

## Reporting a vulnerability

If you find a security issue, please do not open a public issue.

Instead, contact the repository owner through GitHub or LinkedIn with:

- A short description of the issue
- Steps to reproduce it
- The affected file or workflow
- Any suggested fix, if available

## Notes

This project does not require API keys, passwords, or private credentials. It uses publicly available OpenF1 API data.

Please do not submit secrets, private data, paid/proprietary Formula 1 data, or confidential information in issues, pull requests, screenshots, or examples.
